## Xung đột/điểm phải báo trước business code

- CRUD của đề gồm Delete, BR cấm xóa cứng hồ sơ có lịch sử: thiết kế DELETE/logical archive hoặc xóa entity chưa sử dụng phải có semantics/acceptance test rõ; không tự gọi Retire là đã đủ CRUD. Hiện chưa implement Delete.
- Clean Architecture + CQRS vẫn giữ API -> Application Services/Handlers -> Repository abstractions -> Infrastructure Repository/EF -> SQL; minh chứng cấu trúc ở README, không thay yêu cầu bằng pattern khác.
- C1 cũ có internal REST trong khi BR-ARCH-05 chọn gRPC. C1 scaffold mô tả đích gRPC cho internal calls; hiện chỉ hai client Equipment probe được implement. Authorization/registration/reconciliation còn pending.
- Đề cho phép .NET 8 trở lên; baseline nhóm .NET 10 đáp ứng, không bị khóa bởi SDK một thành viên.
- Ba quyết định BR chặn implementation tương ứng: Retire coordination, authorization freshness, reconciliation. Review còn có SLA nghiệm thu, calibration failure và reminder timing; không tự giải quyết bằng cách bỏ rule.

CI đã có file workflow nhưng chưa chạy trên GitHub khi chưa có remote; không ghi CI xanh như kết quả đã có.
